# Contributing

Open an issue describing the ambiguity, correction, or missing pattern. PRs welcome for original notes, Java 11 examples, reproducible tests, and Mermaid diagrams. For changes to an algorithm: state assumptions, brute-force and optimized complexities, an invariant, an edge case, and expected output. For system design: include scale assumptions and at least two reasonable alternatives.

Before sending a PR run `bash scripts/test.sh`. Do not submit employer-confidential materials, private interview questions, or verbatim third-party educational content. Be respectful of other contributors. Java examples must run on Java 11. Practical readability beats excessive cleverness.
